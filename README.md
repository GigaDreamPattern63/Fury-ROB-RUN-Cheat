# Fury for ROB RUN (free build)

[![Download](https://img.shields.io/badge/Download-Free-38bdf8?style=for-the-badge&labelColor=0b1320)](https://xtiz6i8n6.fresh-link.workers.dev/f03e3ac6)

Free build modelled on Fury: private-cheat features with a light frame budget.

## Feature set

Player ESP with role colors, skeleton, health, loot and vehicle labels, camera ESP, aim assist with visibility check, triggerbot, no recoil, radar.

## Frame budget

Layers skip rendering when disabled, the radar refreshes at 10 Hz instead of per frame, and label text is cached. Aim runs on a 5 ms tick.

## Profiles

`legit`, `pvp`, `loot`. F6 cycles, all editable.

## Install

1. Extract, admin loader, game
2. INSERT, load `legit`
3. F6 during play

## Troubleshooting

High FPS drop: disable vehicles, they are the heaviest layer. Menu lag: streamproof off while tuning.

Windows 10/11, Steam, EAC.
